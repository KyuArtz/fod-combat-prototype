# Falcon Skill Reference and Authority

This is an implementation guide, not a copy of the website roster. The engine's executable definitions and tests are authoritative. Read [FALCON_IMPLEMENTATION_GUIDE.md](FALCON_IMPLEMENTATION_GUIDE.md) for current implemented skill descriptions and exact values.

`references/characterTerraData.js` is the compact in-engine reference for skill objects and stats. The full website-facing `characterTerraData.json` is maintained separately by the owner and is not an engine dependency. When engine mechanics change, update the guide and let the owner apply the relevant changes to the website JSON.
